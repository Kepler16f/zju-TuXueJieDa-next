隐私政策

「图学习题解答」（下称"本应用"）由个人开发者 Kepler16f（胡天泽）开发与维护。本政策说明本应用在运行时会收集哪些信息、如何使用与保护这些信息，以及你的权利。

一、我们遵循的原则

本应用为纯本地学习工具：题目内容全部内置在安装包中，你的学习记录（收藏、便签、完成进度）只保存在你设备本地，不会上传到任何服务器，也��收集你的账号、设备标识或位置信息。

二、我们收集的信息

信息来源用途是否上传
题目收藏 / 完成标记 / 便签内容 / 界面偏好（如主题、视图样式）你在应用内的操作仅用于在本机恢复你的学习状态否，仅存储于设备本地沙盒
应用版本号、操作系统与架构应用运行时读取判断是否存在适配本机的更新包否，仅用于本地比对
更新包下载记录你在"检查更新"中主动触发展示下载进度、保存安装包以便安装否，下载文件保存在应用私有目录

三、权限说明

  • 网络访问：仅在你主动点击"检查更新"或下载更新包时使用，用于访问 GitHub Releases 获取版本信息与安装包。应用启动时不会发起任何网络请求。
  • 通知（Android 13 及以上）：仅在"后台下载更新包"时使用，用于显示下载进度条与完成通知。应用启动时不会主动申请。
  • 安装包（Android）：仅在你点击"立即安装"时使用，用于调用系统安装器。
  • 其它权限：本应用不申请通讯录、位置、相机、麦克风、存储等权限。

四、第三方服务

本应用仅在你主动检查更新时访问以下第三方服务，且仅传递更新查询所必需的公开信息：

  • GitHub（api.github.com / github.com）：查询本项目的公开 Release 信息、下载安装包。访问受 GitHub 隐私政策约束。
  • 可选下载镜像（GHProxy / GH-Proxy / GHFast 等）：仅在你在"设置 → 关于"中主动开启并选择时使用，用于改善国内网络下的下载速度。镜像站由第三方运营，其访问日志由镜像站自行处理。

五、数据的存储与保护

  • 学习数据保存在应用私有目录中，卸载应用即随之删除。
  • 更新安装包保存在应用私有目录，升级完成后新版本会清理旧版遗留文件。
  • 我们不会出售、共享或出租你的任何信息。

六、你的权利

  • 查看与修改：在应用内"题库 → 笔记"与"设置 → 学习数据"中查看、编辑或清空收藏、便签与进度。
  • 清空数据：在"设置 → 学习数据"中一键清空学习进度、收藏与便签；或在系统设置中卸载应用。
  • 撤回同意：卸载应用，或在系统设置中清除应用数据。

七、未成年人保护

本应用面向工程图学课程的学习使用。若使用者为未成年人，请在监护人陪同下使用。本应用不收集未成年人的个人信息。

八、政策更新

政策如有变更，将在应用内"设置 → 关于"或本页面公示。继续使用即表示接受更新后的政策。

九、联系我们

如有疑问或权利诉求，请通过 GitHub Issues 联系我们，或邮件联系开发者 Kepler16f。

本应用为非官方学生重制项目，与教材编者及出版方无任何关联。
