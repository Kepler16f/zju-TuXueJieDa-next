# 图学基础教程习题解答 · Next

对经典《图学基础教程习题解答》多媒体课件的非官方学生重制（数字化重构）：基于 Flutter 的跨平台客户端，完整保留 **177 道激活习题** 的真实页码与题号顺序、原题/答案对照、分步作图详解，以及全量 **67 个** 配套三维/投影演示动画。

## 章节结构

章节不再沿用原课件的模块划分，而是按每题的显示页码重新组织（`assets/data/curriculum.json`，schemaVersion 2，由 `tools/regroup_chapters.py` 生成）：

| id | 名称 | 页码范围 | 题数 |
| --- | --- | --- | --- |
| `tyjc` | 投影基础 | 11–31 | 42 |
| `zhst` | 组合体和实体造型 | 32–66 | 66 |
| `gctb` | 工程图表达基础 | 67–87 | 34 |
| `ghyd` | 工程图的绘制与阅读 | 88–116 | 32 |
| `sjgx` | 工程数据常用图形 | 122–124 | 3 |

空章节不单独显示：如"阴影"章当前没有题目，因此不出现在章节列表中；未来若出现页码 ≥ 125 的题，重排脚本会自动生成该章。

## 核心特性

- **精确还原真实页码与题号**：通过逆向解析原版 Director Score（`VWSC`）与 `Cast` 调用关系，修正了文件名与真实显示页码/题号不一致的问题，严格迁移主程序当前可点选的全部 **177 题**。
- **高质量离线图形与文字资产**：
  - 自动剥离旧版 `jieti/*.dir` 中的 Director 翻页/标签栏控件，合成纯净的 `540×450` 分步/多视图图像；
  - 优先采用 `SubAnsTu.cst` 内置更新版原图/答案（含 `p52_1n~4n` 等无外部 `.jpg` 的 `BITD` 位图），并抽取出 177 题 `text.cst` 文字题干与作图步骤 `XMED` 注释；
  - 将 `avi.cst` 及未挂载的 `P111_21.avi` 共 **67 个** Cinepak / MS Video 1 `.avi` 动画统一转码为 H.264 MP4。
- **自适应双页面壳**：桌面端用侧栏、移动端用底栏导航的"题库 + 设置"双页面结构，布局随窗口宽度在约 960px 断点自动切换。
- **完整设置页**：深色主题三态切换（跟随系统/浅色/深色）、Windows 托盘行为开关、Android 重力感应旋屏开关、学习数据统计与清理、关于页。
- **桌面端体验**：Windows 关闭主窗口时最小化到系统托盘（可从托盘再次打开），配合单实例激活——再次启动程序会唤起已有窗口而不是另开进程。
- **移动端体验**：Android 支持重力感应旋转与全面屏 edge-to-edge（内容延伸至状态栏/导航栏后方）；题单与题目详情分别提供抽屉导航。
- **题目便签**：每题可以写一段自己的笔记，随学习数据持久化保存，设置页可一键清空。
- **解题标签按需显示**：只有步骤数大于 3 的题目才显示"解题"页签，短题直接进入原题/答案对照，减少无效点击。
- **内置精简中文字体 AppSansCJK**：应用内打包精简版思源黑体子集，各平台中文渲染一致，不依赖系统字体。
- **简体中文 Inno Setup 安装包**：Windows 端提供中文安装向导（`tools/installer.iss`，语言文件见 `tools/languages/`）。
- **原有工作台与快捷键**：高清白底图纸，支持滚轮/双指缩放、双击复位、按住或空格键一键"原题 ↔ 答案"叠图对比；`←`/`→` 切换步骤，`PageUp`/`PageDown` 切换上下题，`Space` 对比。
- **应用内更新**：Windows / Android / Linux 通过 GitHub Releases 检查更新、带进度下载并拉起安装。

## 目录结构

- `lib/`: Flutter UI（自适应壳层、题目工作台、设置页）、状态仓储与跨平台更新服务
- `assets/data/curriculum.json`: 177 题结构化课程与页码映射索引（schemaVersion 2）
- `assets/subjects/`, `assets/answers/`, `assets/steps/`, `assets/videos/`: 抽离与转码后的现代多媒体资产
- `assets/fonts/`: 内置精简中文字体（AppSansCJK）及其 OFL 许可文件
- `tools/extract_assets.py`: Director 资产逆向抽取与视频转码脚本
- `tools/regroup_chapters.py`: 按显示页码重组章节的幂等脚本（schemaVersion 1 → 2）
- `tools/installer.iss` + `tools/languages/`: Inno Setup 简体中文安装包脚本
- `tools/build_package.ps1`: 版本同步与安装包构建归档脚本
